# Project Rules – Иван Перцев Сайт

## 1. Эталонная версия

* Эталонная версия главной страницы и всех файлов меню зафиксирована в бэкапе `V46`.
* Любые изменения должны делаться **на копии эталонной версии**.

## 2. Бэкапы

* Все промежуточные версии старше `V34` можно удалить.
* Для каждого значительного изменения создается новый бэкап в папке `backup/home`.
* Пример структуры бэкапа:

  ```
  backup/home/
    home-current.html   # текущая рабочая версия
    home-v46-master-stable.html
    home-v46-master-stable.css
    home-v46-master-stable.js
  ```

## 3. Версии файлов для Tilda

* После внесения изменений увеличивать параметр `v=` в ссылках на:

  * CSS: `<link rel="stylesheet" href=".../home.css?v=NN">`
  * JS: `<script src=".../home.js?v=NN"></script>`
  * HTML: `fetch(".../home.html?v=NN")`
* Это позволяет Tilda и браузеру видеть обновлённые файлы.

## 4. Работа с меню и бургером

* Все иконки (крестик, Telegram, VK, Instagram) – одинакового размера (27×27 px на разрешении 1440×800) и адаптированы под другие разрешения.
* Крестик:

  * Две линии должны соединяться строго по центру.
  * Анимация крестика должна быть плавной, без дерганья.
* Аккордеоны:

  * Стрелки – размер 14×23 px.
  * Анимация плавная, стрелка поворачивается при раскрытии на 180° и становится 50% прозрачной.
  * Текст аккордеона в разделе "Контакты" появляется по отдельности (строки не перекрываются).

## 5. Текст и подзаголовки

* Заголовок на главной странице – **все заглавные буквы**.
* Подзаголовок ведущий·музыкант – можно корректировать вертикальное положение без изменения анимации.
* Анимация текста меню должна быть такой же, как для заголовка и подзаголовка, с задержкой после появления иконок соцсетей.

## 6. Фон меню

* Черный с прозрачностью 30% и `backdrop-filter: blur(25px)`.
* На него наложен шум с прозрачностью 35%.
* Не использовать полностью черные непрозрачные блоки вместо эффекта матового стекла.

## 7. Ховер эффект

* Иконки соцсетей: плавное появление цвета при наведении, без дергания и мерцания.
* Текст меню:

  * Основной – белый `#FFFFFF`.
  * Аккордеоны – голубой `#69C9FF`.
  * Правовые ссылки – белый с 50% прозрачности.

## 8. Кэш и публикация

* После внесения изменений **обязательно публиковать страницу** в Tilda.
* Иногда изменения могут не отображаться сразу из-за кэша. Обновите страницу или используйте `v=` версию.

## 10. Общие правила

* Все изменения в коде – только через бэкапы.
* Работать последовательно: сначала HTML, затем CSS, затем JS.
* Любые изменения анимаций, меню, крестика, стрелок или текста согласовывать.
